# PIRI FLAME Receipts

A phone web app for recording supplier receipts.

- Stays in the camera and takes the photo by itself when the receipt is sharp and steady, then waits for the next one.
- Each photo is read by Claude (Arabic and English) in the background. Clear receipts are saved automatically; doubtful ones are highlighted for a quick check.
- Export a CSV with the columns of the PIRI FLAME INVOICES sheet's Expense tab: Date, ID, Category, Description, Total Amount, Account.

Everything is stored on the phone. The Anthropic API key you enter in Settings stays in the browser's local storage and is sent only to api.anthropic.com.

Open the published page on an iPhone, then Share, then Add to Home Screen.
